# Project for CS2

## What it is: 
This Projects is a 3d based Raylib archery "game" named Targets. You move around and shoot targets, there are 4 differnt gamemodes to choose from.


## How to build and run: exact commands:
- cmake -S . -B build
- cmake --build build
- ./build/targets

## How to use it: 
#### Use keys that are prompted to you,
#### additional,
- 'M' - Menu
- 'Esc' - Exit

#### To move around use 
- 'w' - forward
- 'A' - left
- 'S' - back
- 'D' - right
  
#### Arrows to aim
- '←' - Left 
- '→' - Right
- '↑' - Up
- '↓' - Down
- hold 'spacebar' to charge arrow,  release 'spacebar' to shoot
